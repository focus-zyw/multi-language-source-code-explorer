# 项目学习能力

工作台顶部「项目总览」集中提供项目入口、文件依赖、学习导航与结构化搜索。
URL 使用原有 `view=explore&root=project`，额外用 `overview` 记住所选总览。
点击依赖文件、排行或搜索结果回到源码，现有 AI 任务继续使用原生命周期。

## 文件依赖

复用导入快照中的 `files.imports`，不是运行时加载追踪，也不把导入当调用。
确定目标、推断目标、外部与无法解析分别保留。Java/Go 等包导入可能只有代表文件，
目录聚合只是路径归组，不是语言级包解析。

图中逐层显示所选节点的正向/反向一层邻居，最多 61 个节点，点击节点继续追踪。
关系上限 20000，边界条目另限 20000，超出明确提示；循环结论仅对保留关系有效。
同一目标的多处导入合并计数，已解析与推断边不合并；保存前 20 个位置/说明符。
反向边用曲线避开正向边。路径在图节点内简写，悬停和详情可查看完整路径。

循环用非递归强连通分量检测，支持自环；列表表示循环组，不声称其排列就是某条环路。
默认排除推断边，也可查看包含推断边的可能循环。目录内部边在聚合图中省略，循环仍按文件检测。

## 学习导航与搜索

学习排行只统计非测试的函数/方法，排除类和 HTML/JSON 结构节点。
确定调用方、推断调用方、候选调用方分别按调用方方法去重，不将静态引用当运行频率。
排行上限 20，用于学习导航，不是质量评分或跨语言性能比较。

结构化搜索在服务端校验筛选条件、项目归属、长度与页码，每页返回 40 项，不传整份源码。
注解和基类仅做保存文本的大小写不敏感匹配；TypeScript `implements` 等未记录事实不会被补猜。
弃用标记检查已提取文档中的 `@deprecated` 和装饰器/注解中的 `@Deprecated`。

## 框架约定与缓存

- Spring：类级 `RequestMapping` 字面量与方法路径合并，支持路径数组及 `RequestMethod` 动词。
- Python：点号路由装饰器的字面量路径及 `methods`；不推测挂载前缀。
- Nest 风格：按 `Controller` 与 `Get/Post/...` 名称组合类/方法字面量。

上述均标为约定识别，没有验证框架导入来源或运行时注册。动态表达式不求值，
无法确定、截断及超限情况保留不完整提示。最多 32 条路径、8 条证据；不执行装饰器。
真实 Tree-sitter 测试覆盖 Java/Python/TS，并修复 TS 装饰器位于导出包装层或方法前兄弟节点时遗漏的问题。
展示范围包含方法装饰器，定义范围仍用于定位方法 AST。

含装饰器的 JS/TS/Vue 讲解采用指纹版本 3 并包含装饰器事实，避免旧讲解误复用。
其他语言及未装饰方法保持原规则。入口路由推断不自动加入 AI 提示词，不伪装成源码调用。

## 扫描优化边界

分段记录分析流水线耗时，保存到已有项目统计 JSON，无数据库结构迁移。
测量不包含目录遍历/上传/网络，合计截至事务提交前。
失败仍回滚整次替换，不改变已有项目身份或缓存归属机制。
运行数据 `data/` 与临时工具目录 `.cache/` 排除出应用类型检查，避免本地导入的源码参与应用编译。

本轮先提供测量，没有实现解析缓存或完整增量。小型样例的耗时不能代表大型项目；
应在目标项目上比较首次导入、无变化重扫及少量修改重扫后，再决定是否缓存解析结果。

## 验证

定向单测：

```powershell
rtk proxy node --test tests/project-insights.test.ts tests/symbol-search.test.ts tests/route-hints.test.ts tests/project-entries.test.ts tests/explanation-fingerprint.test.ts
```

隔离后端集成（先构建）：

```powershell
rtk npm run build
$env:RUN_INSIGHTS_E2E="1"
rtk proxy node --test tests/project-insights.integration.test.mjs
```

该测试自行启动独立应用，使用临时数据库和源码，关闭真实 AI，覆盖项目隔离、循环、分页、路由证据、重扫更新和耗时。
缓存兼容另用 `RUN_BACKEND_E2E=1` 的既有模拟 API/Agent 集成测试验证，不消耗真实模型用量。
