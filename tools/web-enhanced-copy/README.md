# Code Atlas 增强复制

Chrome／Edge 的 Manifest V3 扩展，无需安装依赖或构建。仅支持浏览器网页，不能用于 ChatGPT 官方桌面客户端。

## 安装

1. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录（包含 `manifest.json`）。如果收到 ZIP，请先解压。
4. 在浏览器工具栏的扩展菜单中，将「Code Atlas 增强复制」固定到工具栏。

更新本目录的文件后，在扩展管理页点击该扩展的「重新加载」，并刷新需要复制的网页。

## 使用

1. 打开 ChatGPT 网页，等待回复完成。
2. 点击工具栏的扩展图标，再点击「启用回复复制按钮」。
3. 关闭扩展弹窗，点击目标回复上方的「增强复制」。
4. 页面右下角显示「已复制」后，打开 Code Atlas，选中文件，在文件笔记中粘贴。
5. 继续追加或修改正文，点击「保存笔记」。

只为当前已加载的回复添加按钮；启用期间新加载的回复会自动添加按钮。刷新网页后需重新启用。其他网页、ChatGPT 页面改版或回复识别失败时，使用「选择页面区域」：移动鼠标查看边框，点击锁定区域，可点击「扩大选区」，再点击「复制所选区域」。Esc 取消选择。页面右下角「关闭」或弹窗「关闭本页工具」会移除本次添加的按钮和观察器。

## 保留范围

- 标题、正文、列表、普通表格转成可编辑 Markdown。
- 代码保留页面已有的字符与换行，保留可识别的语言标签；外观沿用笔记渲染器。
- 有 LaTeX 标注的 KaTeX／MathJax／MathML 公式转成公式源码。
- 多列 Grid、并排卡片会读取计算样式，保留列数、颜色、间距等静态布局。布局附件内部文字暂不能逐项编辑。
- 能从页面读取像素的图片会嵌入并保存为本地附件；跨域限制、未加载或过大的图片可能只保留原链接，并明确提示。SVG、Canvas、iframe 等需手动补充截图。

工具同时写入 `text/html` 和 `text/plain`。粘贴到 Code Atlas 优先使用增强 HTML；其他应用是否保留布局取决于其粘贴能力。纯文本后备包含 Markdown 与布局中的文字，不承诺保留图示排版。

复制单条回复最多 4000 个采集节点、32 层、2MB HTML；单个布局最多 240KB；图片每张最多 1MB。工具不截断内容，超限提示分段。文件笔记追加后的正文最多 32KB，图片与布局附件使用项目已有的附件额度。代码原文本身已无换行时不会猜测修复。网页未加载或被虚拟化移除的内容需先加载后复制。

## 权限与隐私

权限仅 `activeTab`、`scripting`、`clipboardWrite`。点击扩展后才注入当前页，使用隔离的内容脚本；不读取账号存储、其他页面或内部应用状态，不调用模型，也不上传内容。读取网页 DOM 和计算样式不是读取 ChatGPT 内部源代码。图片嵌入只读取页面已加载的像素，不额外请求图片服务器；链接图片在笔记预览时仍可能联网加载。

不申请所有网站常驻权限，不读取原剪贴板，不自动连接本地 Code Atlas 服务。扩展只导出静态内容；笔记端再次按允许列表解析，不执行复制内容中的脚本或事件。

## 验证

仓库根目录运行 `node --test tests/web-enhanced-copy.test.mjs` 检查扩展配置、脚本语法与导入约定。

浏览器端到端测试需要先构建应用和安装 Playwright／Chromium。在 PowerShell 设置 `$env:RUN_WEB_COPY_UI="1"` 后运行 `node --test tests/web-enhanced-copy-ui.test.mjs`。可用 `PLAYWRIGHT_MODULE` 指定 Playwright 的 `index.mjs`，`WEB_COPY_CHROMIUM` 指定支持扩展的 Chromium 可执行文件。测试使用独立浏览器目录、临时项目和数据库，不连接已有服务、不调用真实 AI。测试既检查真实扩展注入，也检查剪贴板、笔记粘贴、本地附件和刷新保留。
